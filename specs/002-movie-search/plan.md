## Summary

matching the reference app at
`/Users/karimelbahi/Programming/Android/Study/Flutter/flutter-tmdbmovie-bloc-cubit`.

vertical result list (poster + title + year), clear button, loading / empty / error states,
and tap → movie detail placeholder (until `003-movie-detail`).

## Cubit Design Notes

**States** (Equatable, sealed-style naming):

| State | UI |
|-------|-----|
| `SearchMoviesInitial` | Blank body (no list) |
| `SearchMoviesLoading` | Center `CircularProgressIndicator` |
| `SearchMoviesSuccess(movies, query)` | `ListView` of `ListTileSearch` |
| `SearchMoviesEmpty(query)` | Center empty message |
| `SearchMoviesFailure(message, query)` | Center error + retry |

**Stale-request guard**: Cubit tracks `_latestQuery`; ignore responses where `query != _latestQuery`.

**Empty query**: Do not call API; emit `Initial` (reference resets on clear).
